# 03. Design

| 선택 | 대안 | 근거 | 트레이드오프 |
| --- | --- | --- | --- |
| **1) 백엔드** — FastAPI | Django, Express | Python 3.11 이상과 잘 맞고, Pydantic 검증과 자동 API 문서가 기본 제공된다. 7개 API 규모에 가볍다. | Django 의 관리자·인증 기능은 직접 만들어야 한다. 검증 실패가 기본 422 라 400 으로 바꾸는 예외 핸들러가 필요하다. |
| **2) 프론트** — Vanilla JS + Tailwind CDN (`index.html`, `app.js` 2개 파일). 백엔드가 같은 오리진에서 제공하며 `file://` 로 직접 열지 않는다. | React, Vue | 빌드 도구 없이 파일 2개로 끝나 유지보수 부담이 작다. 같은 오리진이라 CORS 설정이 필요 없다. | 화면이 커지면 DOM 코드가 길어진다. CDN 이라 오프라인에서는 스타일이 적용되지 않는다. |
| **3) DB** — SQLite (SQLAlchemy ORM, 추후 PostgreSQL 전환 고려) | PostgreSQL 즉시 도입 | 설치와 서버 없이 파일 하나로 동작한다. ORM 을 쓰므로 PostgreSQL 로 옮길 때 코드 변경을 줄일 수 있다. | 동시 쓰기에 약하다. 전환 시 `AUTOINCREMENT` 같은 SQLite 전용 설정은 다시 확인해야 한다. |
| **4) CSS** — Tailwind 만. styled-components 금지 | styled-components, 직접 작성한 CSS | 스타일 방식을 하나로 고정해 읽기 쉽고, CDN 으로 바로 쓸 수 있다. | 클래스 이름이 길어진다. CDN 방식은 빌드 최적화(미사용 CSS 제거)를 못 한다. |
| **5) 받아쓰기** — Gemini API (`gemini-3.1-flash-lite`). 키는 `.env` 로만 읽고 저장소에 올리지 않는다. | Whisper 자체 구동, 브라우저 음성 인식 | 서버에 모델을 올리지 않고 API 호출만으로 받아쓰기와 세 갈래 구분을 같은 서비스에서 처리한다. | 외부 호출이라 실패할 수 있다(`02-specs.md` 의 502 와 구분 실패 처리). 사용량 비용과 네트워크 의존이 생긴다. |
| **6) 상태관리** — 모듈 변수 + DOM 직접 갱신 | 상태관리 라이브러리, 프레임워크 | 화면 4종 규모에 충분하고 의존성이 없다. | 상태가 늘면 어디서 바뀌는지 추적하기 어렵다. 갱신 코드를 직접 관리해야 한다. |
| **7) 디자인 시스템** — Mac OS UI 톤(둥근 모서리, 부드러운 그림자, 반투명 카드, 시스템 폰트). 화면 요소 이름은 `docs/화면구성.pdf` 5쪽 id 표를 그대로 옮긴다. 한 번 정하면 바꾸지 않고, 바꿔야 하면 사유를 먼저 적는다.<br><br>**공통 배치**: 상단 고정 헤더에 제목(MeetingNote)과 탭 3개(목록·넣기·할일), 테마 버튼. 본문은 최대 폭 `max-w-6xl` 가운데 정렬.<br><br>**목록**: 상단에 검색 입력(`q`, `from`, `to`), 아래에 카드 구역(`cards`). 카드는 2열이고 360px 에서는 1열. 카드에는 제목, 날짜·참석자, 요약 첫 줄을 표시한다. 카드를 누르면 상세. 검색은 입력할 때마다 다시 부른다.<br><br>**넣기**: 제목(`title`), 일시(`metAt`, datetime-local), 참석자(`attendees`), 파일 선택(`file`)과 받아쓰기 버튼(`btnUp`)과 상태 문구, 본문(`body`), 정리하기 버튼(`btnSave`)과 저장 상태 문구, 결과 세 칸(`result`: 요약·결정사항·할일).<br><br>**상세**: 가운데 겹침 창(`modal`). 제목, 일시·참석자, 요약·결정사항·할일 세 칸, 접힌 받아쓴 본문, 제목 수정칸(`mTitle`)과 제목 수정 버튼, 삭제 버튼(한 번 더 눌러야 삭제). 바깥 어두운 영역을 누르면 닫힌다.<br><br>**할일**: 내용·담당자·기한·회의 열의 표. 본문 행은 `todoBody`. 좁은 화면에서는 표만 가로 스크롤하고 문서 전체의 가로 스크롤은 금지.<br><br>**요소 id**: `q` · `from` · `to` · `cards` · `title` · `metAt` · `attendees` · `file` · `body` · `btnUp` · `btnSave` · `result` · `modal` · `mTitle` · `todoBody` | Material, Ant | 화면 요소 이름과 배치를 한곳에 고정해 두면 화면을 다시 만들어도 id 가 흔들리지 않고, 코드·테스트·문서가 같은 이름을 쓴다. Mac OS 톤은 비개발자 사용자에게 익숙하다. | 컴포넌트 라이브러리를 쓸 때보다 스타일을 직접 만들어야 한다. id 를 바꾸려면 문서 수정 사유가 먼저 필요해 변경이 느리다. |
| **8) 테마** — 라이트/다크 토글, `localStorage` 에 저장, 초기값은 시스템 설정 | 라이트 고정, 서버에 저장 | 사용자 환경에 맞춰 시작하고, 직접 고른 값은 새로고침해도 유지된다. 서버 저장이 필요 없다. | `localStorage` 가 막힌 환경에서는 유지되지 않는다. 기기마다 따로 저장된다. |

03-design 에 사유를 적기 전에는 새 의존성을 도입할 수 없다.

사전 승인 목록:

| 패키지 | 사유 |
| --- | --- |
| `httpx` | 테스트 구동(FastAPI `TestClient` 가 필요로 함) |
| `google-genai` | Gemini API 받아쓰기 |

| `python-multipart` | `POST /api/upload` 의 파일 업로드 수신(FastAPI 필수) |
| `python-dotenv` | `.env` 에서 `GEMINI_API_KEY`, `GEMINI_MODEL` 읽기 |
